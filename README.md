# PostgreSQL Finance Analytics

Financial data analytics project using PostgreSQL for querying, aggregating, and reporting on financial datasets.

## Overview

This project demonstrates SQL-based financial analytics: building structured queries for KPIs, trend analysis, and financial reporting directly in PostgreSQL.

## Tech Stack

**PostgreSQL** · **Python** · **Pandas** · **Jupyter Notebook**

## Project Structure

```
├── notebook/          # Analysis notebooks
├── data/              # Financial datasets
├── .gitignore
└── requirements.txt
```

## Analytics Covered

- Revenue and cost aggregations by period
- Profitability metrics and margins
- Time-series trend analysis
- Comparative reporting across segments
- Window functions for running totals and rankings

## How to Run

1. Set up PostgreSQL and load the dataset
2. Install dependencies: `pip install -r requirements.txt`
3. Run notebooks in `notebook/` folder
